# Lightberry

> Lightberry builds conversational AI "personality" software for robots. Robots running Lightberry
> listen, speak, perceive their surroundings, and act on natural-language instruction without the
> owner writing code. The company is a Y Combinator Fall 2025 startup based in San Francisco, and
> ships its software pre-installed on robots through a partnership with Unitree.

## Docs

- [Lightberry Docs](https://docs.lightberry.com): Notion-hosted documentation.
- Quick Start Guide: power on (micro USB, green light, ~90s boot), connect to WiFi via the
  BTBerryWifi app (device advertises as "lb"), start a conversation (500ms-1.5s response time),
  and set up an assistant.
- MCP Architecture: an MCP server runs on the Lightberry server; each Lightberry device functions
  as a REST API endpoint; the MCP server routes tool calls to the correct device id, resolving the
  device IP via Tailscale. No server URL, transport, or tool list is published.

## Hardware and partners

- Robot Store: officially partnered with [Unitree](https://unitree.com); robots ship with

- Manufacturer compatibility program covering Unitree, Fourier, Booster Robotics, and High Torque
  platforms (G1, GR-2/N1, T1/K1, Mini-Pi series).
